# Csatapályák – pályalapok

A `tools/skirmish_palyak.py` állítja elő. Pályánként: a jellegzetes döntés, felállások, a semleges táborok népei szintenként, díszletek és háttérszereplők. A táborok népe szintenként egyféle (nem keveredik a vadon lényeivel); a zsákmány a vadon azonos szintű táboráé (a hős felveheti).
